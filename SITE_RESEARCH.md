# SITE_RESEARCH.md — Исследование https://www.dayardan.com

Дата исследования: 2026-11-03. Исследователь: автономный агент (Claude Code, облачная сессия).

## 1. Статус доступа к сайту из среды производства

| Проверка | Результат |
|---|---|
| `curl https://www.dayardan.com` из контейнера | `CONNECT tunnel failed, response 403` — сетевая политика сессии запрещает хост |
| `curl https://dayardan.com` | та же ошибка 403 от egress-прокси |
| Playwright (`scripts/capture-site.ts`, Chromium 1243, iPhone 13 профиль) | `net::ERR_TUNNEL_CONNECTION_FAILED at https://www.dayardan.com/` |
| WebFetch (внешний fetch-сервис) | `getaddrinfo ENOTFOUND www.dayardan.com` — хост вне разрешённых доменов |
| Wayback Machine (`archive.org`, `web.archive.org`) | `403` — тоже запрещён политикой |
| Папки/компьютеры пользователя через Remote Control | не подключены (список пуст) |
| GitHub-репозитории с исходным кодом сайта | не найдены (доступен только `adiletgpt6-beep/dayardan`, пустой) |

**Вывод:** в этой облачной сессии невозможно открыть сайт, сделать реальные скриншоты или записи экрана.
Хост `www.dayardan.com` (и `dayardan.com`) нужно добавить в *Allowed domains* сетевых настроек окружения
(Cloud environment → Edit → Network access), после чего запускается:

```bash
PLAYWRIGHT_BROWSERS_PATH=/opt/pw-browsers npx tsx scripts/capture-site.ts   # делает скриншоты + запись + recordings/manifest.json
npm run build:manifest && npm run render:all                                 # перерендер 15 роликов с реальным интерфейсом
```

Скрипт захвата готов и протестирован до момента сетевого отказа (ошибка выше получена именно из него).

## 3. Что НЕ подтверждено (и поэтому не показывается в роликах как факт)

- Регистрация / вход / личный кабинет — не подтверждены. Ролик DAY-009 адаптирован: вместо «регистрации» он объясняет
  страницу «Кантип иштейт?» и три шага старта. Если регистрация есть, сценарий DAY-009-alt в `CONTENT_PLAN.md` заменяет его.
- Таймер в тесте — не подтверждён, в роликах не упоминается.
- Детальный разбор каждой ошибки — не подтверждён; подтверждён только показ результата и слабых тем, ролики говорят именно это.
- Фирменные цвета/логотип — не получены (сайт недоступен). Используется временная палитра (см. `STYLE_GUIDE.md`),
  логотип не используется — только текстовый знак «Dayardan» и адрес `dayardan.com`.

## 4. Как реальный интерфейс попадает в ролики

- `recordings/manifest.json` (создаётся `scripts/capture-site.ts`) сопоставляет ключи `home`, `how-it-works`,
  `discovered-N`, `home-scroll` с файлами в `screenshots/` и `recordings/`.
- Компонент `ScreenRecording` показывает реальный файл внутри `PhoneMockup`, если ключ есть в манифесте.
- Если ключа нет — показывается нейтральная моушн-карточка с адресом сайта и названием шага.
  Нарисованная имитация интерфейса **не используется**.
