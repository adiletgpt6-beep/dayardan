# Dayardan — Video Production System

Автономная система производства 15 вертикальных (9:16, 1080×1920, 30 fps, 55–60 s) промо- и обучающих роликов
на кыргызском языке для платформы подготовки к ЖРТ (ОРТ) **https://www.dayardan.com**.

Стек: Remotion + React + TypeScript, Playwright (захват реального интерфейса), ElevenLabs (кыргызская озвучка), FFmpeg.

См. `STATUS.md`, `HANDOFF.md`, `CONTENT_PLAN.md`, `SITE_RESEARCH.md`, `STYLE_GUIDE.md`.
