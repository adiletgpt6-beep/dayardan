# STYLE_GUIDE.md — Фирменный стиль роликов Dayardan

> Палитра **временная**: сайт недоступен из среды производства (сетевая политика), реальные фирменные цвета и логотип не получены.
> После `npm run capture` сверьте цвета со скриншотами и обновите `src/theme.ts` — все компоненты берут цвета оттуда.

## Цвета (`src/theme.ts`)
| Токен | Значение | Применение |
|---|---|---|
| primary | #2563EB | кнопки на «экране», синий фон (tone=blue), бренд-точка |
| primaryDark | #1E3A8A | градиент синего фона |
| navy / navy2 | #0B1437 / #101C4D | тёмный фон (tone=dark), текст на жёлтом |
| accent | #FACC15 | CTA-кнопка, подсветка кнопок, активное слово субтитров, hook-фон |
| accent2 | #F97316 | градиент жёлтого фона |
| success / danger | #22C55E / #EF4444 | статусы |
| screenBg / screenText | #F5F7FF / #0F172A | фон и текст моушн-карточки экрана |

## Типографика
Inter (400/600/700/800/900, latin + cyrillic + cyrillic-ext — покрывает ң, ө, ү). Заголовки 900, подзаголовки 700, субтитры 800.
`fitFontSize()` автоматически уменьшает кегль для длинных кыргызских слов, чтобы текст не обрезался.

## Безопасные зоны (9:16)
Верх 200 px (бренд-знак на 160 px), низ 320 px свободен от важного текста. Субтитры на y≈1500. Телефон: 640×1320 @0.9, y=230.

## Компоненты (`src/components`)
Intro · Outro · PhoneMockup · ScreenRecording · AnimatedCursor · ButtonHighlight · ZoomEffect · DynamicSubtitles · CallToAction ·
Background · KineticText · Icon · Wordmark. Сцены: hook, statement, title, phone, steps, features, cta (`src/scenes/SceneRenderer.tsx`).

## Движение
Spring-анимации (damping 12–16), перекрытие сцен 10 кадров с fade+slide, «вуш» на смене сцен (−13 дБ), «success» на CTA.
Hook: белая вспышка 6 кадров + кинетический текст. Телефон влетает с 3D-наклоном −28°→−6° и лёгким покачиванием.
Статичных сцен длиннее ~8 с нет: тайминг сцен следует за речью диктора.

## Субтитры
Караоке: до 5 слов / ~30 символов на строку, разбиение по предложениям, активное слово — жёлтое с увеличением 8 %,
строка держится до начала следующей (≤1.2 с). Текст 1:1 совпадает с речью (из выравнивания ElevenLabs).

## Звук
Голос −0 дБ, SFX −13…−12 дБ. Фоновая музыка не используется (по ТЗ).
